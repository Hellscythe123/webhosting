ข้อตกลงการใช้งานบริการ

ปรับปรุงล่าสุด: พ.ศ. 2569

MinimalCloud ("ผู้ให้บริการ") เป็นผู้ให้บริการเว็บโฮสติ้งและบริการที่เกี่ยวข้อง การสมัครใช้บริการ ("บริการ") ของท่าน ("ผู้ใช้บริการ") ถือว่าท่านได้อ่านและยอมรับข้อตกลงและเงื่อนไขดังต่อไปนี้ทุกประการ

1. บัญชีผู้ใช้และความรับผิดชอบ
  • ข้อมูลส่วนตัว: ผู้ใช้บริการต้องให้ข้อมูลที่เป็นจริง ถูกต้อง และเป็นปัจจุบันในการสมัคร หากผู้ให้บริการตรวจพบว่าข้อมูลเป็นเท็จ ขอสงวนสิทธิ์ในการระงับหรือยกเลิกบริการโดยไม่ต้องแจ้งให้ทราบล่วงหน้า
  • ความรับผิดชอบ: การกระทำใดๆ ที่เกิดขึ้นภายใต้บัญชีของผู้ใช้บริการ รวมถึงเนื้อหาบนเว็บไซต์และอีเมล ถือเป็นความรับผิดชอบของผู้ใช้บริการแต่เพียงผู้เดียว ผู้ให้บริการไม่มีส่วนเกี่ยวข้องใดๆ ทั้งสิ้น
  • รหัสผ่าน: ผู้ใช้บริการต้องเก็บรหัสผ่านเป็นความลับ และควรเปลี่ยนรหัสผ่านอย่างสม่ำเสมอเพื่อความปลอดภัย
2. การใช้งานที่ไม่ได้รับอนุญาต (Prohibited Use)

ห้ามใช้บริการในลักษณะต่อไปนี้โดยเด็ดขาด:

  • เนื้อหาผิดกฎหมาย: เผยแพร่เนื้อหาที่ผิดกฎหมาย, ละเมิดลิขสิทธิ์ (เช่น โปรแกรมเถื่อน, ไฟล์เพลง/หนัง), ลามกอนาจาร, การพนัน, หรือเนื้อหาที่ขัดต่อศีลธรรมอันดี
  • ความมั่นคงของชาติ: เผยแพร่ อ้างอิง หรือดูหมิ่นสถาบันชาติ ศาสนา และพระมหากษัตริย์
  • สแปม (SPAM): ส่งอีเมลที่ผู้รับไม่ยินยอมหรือไม่ได้รับอนุญาต ไม่ว่าจะส่งจากเซิร์ฟเวอร์โดยตรงหรืออ้างอิงถึงก็ตาม
  • การโจมตีระบบ: ใช้บริการเพื่อโจมตีระบบอื่น (เช่น Hacking, Cracking, DDoS, Port Scanning) หรือกระทำการใดๆ ที่เป็นอันตรายต่อระบบเซิร์ฟเวอร์ของผู้ให้บริการหรือผู้ใช้งานอื่น
  • การใช้ทรัพยากรเกินขีดจำกัด: ติดตั้งโปรแกรมหรือสคริปต์ที่ใช้ทรัพยากรเซิร์ฟเวอร์ (CPU, RAM) หนักเกินไปจนส่งผลกระทบต่อผู้ใช้งานท่านอื่น
3. การชำระเงิน, เครดิต และการระงับบริการ
  • การชำระเงิน: บริการทั้งหมดเป็นแบบชำระเงินล่วงหน้า ผู้ใช้บริการต้องชำระค่าบริการก่อนครบกำหนดเพื่อใช้งานอย่างต่อเนื่อง
  • ระบบเครดิต: เครดิตที่เติมเข้าระบบใช้สำหรับชำระค่าบริการต่างๆ ของเราเท่านั้น เครดิตคงเหลือในบัญชีไม่สามารถแลกเปลี่ยนเป็นเงินสดหรือขอคืนได้ในทุกกรณี
  • การระงับบริการ: ผู้ให้บริการขอสงวนสิทธิ์ในการระงับบริการชั่วคราว หากผู้ใช้บริการไม่ชำระค่าบริการภายใน 2 วันหลังครบกำหนด
  • การลบข้อมูล: หากไม่ชำระค่าบริการ ผู้ให้บริการจะลบข้อมูลทั้งหมดของผู้ใช้บริการออกจากระบบตามกำหนดเวลาดังนี้:
    • Hosting: ภายใน 7 วันหลังครบกำหนด
    • VPS / Cloud Server: ภายใน 2 วันหลังครบกำหนด
  • การคืนเงิน (Refund): การรับประกันความพึงพอใจและการคืนเงินจะมีผลเฉพาะบริการ Shared Hosting ตามที่ระบุในหน้าสั่งซื้อเท่านั้น บริการประเภทอื่นและการยกเลิกบริการอันเนื่องมาจากการทำผิดข้อตกลง ผู้ให้บริการขอสงวนสิทธิ์ไม่คืนเงินค่าบริการในทุกกรณี
4. การรับประกันและข้อจำกัดความรับผิด
  • การสำรองข้อมูล: ผู้ให้บริการมีการสำรองข้อมูลอย่างสม่ำเสมอ แต่ไม่รับประกันความเสียหายหรือการสูญหายของข้อมูล ผู้ใช้บริการควรสำรองข้อมูลสำคัญของตนเองไว้เสมอ
  • การย้ายข้อมูล: ผู้ให้บริการจะย้ายข้อมูลให้ฟรีเฉพาะครั้งแรกที่สั่งซื้อบริการ Hosting เท่านั้น
  • ความเสถียรของระบบ: ผู้ให้บริการจะพยายามอย่างเต็มที่เพื่อรักษาเสถียรภาพของระบบ แต่จะไม่รับผิดชอบต่อความเสียหายใดๆ ที่อยู่นอกเหนือการควบคุม
5. การเปลี่ยนแปลงและยกเลิกข้อตกลง

ผู้ให้บริการขอสงวนสิทธิ์ในการเปลี่ยนแปลงข้อตกลงนี้ได้ตลอดเวลา โดยจะมีการแจ้งให้ทราบผ่านช่องทางที่เหมาะสม และขอสงวนสิทธิ์ในการปฏิเสธหรือยกเลิกบริการแก่ผู้ที่ละเมิดข้อตกลงโดยไม่จำเป็นต้องแจ้งให้ทราบล่วงหน้า
