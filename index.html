## ขั้นตอนการสมัครสมาชิก (Account Registration)

ระบบ MinimalHouse ให้บริการลงทะเบียนใช้งานสำหรับผู้ใช้งาน 3 รูปแบบตามประเภทนิติสัมพันธ์และเอกสารทางภาษี:

### 1. การเลือกประเภทบัญชี (Account Types)
1. เข้าไปที่หน้าแรกของเว็บไซต์ แล้วคลิกปุ่ม **"สมัครสมาชิก (Register)"** ที่แถบเมนูด้านบน
2. เลือกประเภทบัญชีที่สอดคล้องกับการใช้งานของคุณ:
- **บุคคลทั่วไป (Individual):** สำหรับบุคคลธรรมดาหรือฟรีแลนซ์ ใช้งานบริการส่วนบุคคล
- **นิติบุคคล / บริษัท (Corporate):** สำหรับบริษัทจำกัด ห้างหุ้นส่วนจำกัด หรือองค์กรธุรกิจ เพื่อใช้ออกใบกำกับภาษีเต็มรูปแบบ
- **หน่วยงานราชการ / รัฐวิสาหกิจ (Government):** สำหรับส่วนราชการ สถานศึกษา และหน่วยงานรัฐ

---

### 2. ข้อมูลที่ต้องระบุตามประเภทบัญชี
- **บุคคลทั่วไป:**
- ชื่อ - นามสกุลจริง (ภาษาไทย หรือ อังกฤษ)
- เลขประจำตัวประชาชน 13 หลัก (ระบบมีระบบตรวจสอบความถูกต้อง Checksum Modulo 11 ตามมาตรฐานกรมการปกครอง)
- อีเมลหลักสำหรับรับข้อมูลและรหัสผ่าน
- หมายเลขโทรศัพท์มือถือที่ติดต่อได้
- รหัสผ่านความปลอดภัยสูง (อย่างน้อย 8 ตัวอักษร ประกอบด้วยตัวพิมพ์เล็ก พิมพ์ใหญ่ และตัวเลข)
- **รหัสผู้แนะนำ (Referral Code):** หากมีรหัสจากเพื่อน ให้ระบุในช่องนี้เพื่อรับโบนัสเครดิตใช้งานฟรีตามโปรโมชัน
- **นิติบุคคล / บริษัท:**
- เลขประจำตัวผู้เสียภาษีอากร 13 หลัก (Tax ID)
- ชื่อบริษัท / องค์กรตามหนังสือรับรองกระทรวงพาณิชย์
- ชื่อผู้มีอำนาจลงนาม หรือผู้ติดต่อหลัก
- สำนักงานใหญ่ หรือระบุรหัสสาขา
- ที่อยู่สำหรับออกใบกำกับภาษีและจัดส่งเอกสาร
- **หน่วยงานราชการ:**
- เลขประจำตัวผู้เสียภาษีหน่วยงาน
- ชื่อส่วนราชการ / กรม / กอง / สถาบัน
- ที่อยู่หน่วยงานราชการ

---

### 3. การยืนยันอีเมลและการเข้าสู่ระบบ (Email Verification & Login)
1. เมื่อกรอกข้อมูลครบถ้วนแล้ว ให้กดปุ่ม **"ยืนยันการสมัครสมาชิก"**
2. ระบบจะจัดส่งอีเมลยืนยันตัวตนไปยังอีเมลที่ท่านลงทะเบียนไว้
3. เปิดกล่องข้อความในอีเมล แล้วคลิกปุ่ม **"ยืนยันที่อยู่อีเมล (Verify Email Address)"**
4. เมื่อยืนยันสำเร็จ ระบบจะนำท่านเข้าสู่แดชบอร์ดหลักของ MinimalHouse ทันที พร้อมรับสิทธิประโยชน์และเริ่มต้นสั่งซื้อบริการได้ทันที

## ขั้นตอนการเติมเครดิตเข้าสู่ระบบ (Credit Top-up)

ระบบ MinimalHouse ใช้ระบบกระเป๋าเงินดิจิทัล (Wallet Credit) เพื่อความสะดวกรวดเร็วในการชำระค่าบริการโฮสติ้ง จดโดเมน ต่ออายุ และสั่งซื้อ Cloud VPS โดยไม่ต้องตัดบัตรเครดิตซ้ำทุกครั้ง

---

### 1. เข้าสู่หน้าเติมเครดิต
1. เข้าสู่ระบบบัญชีผู้ใช้ของคุณ
2. ดูที่แถบเมนูด้านบนขวา หรือเมนูฝั่งซ้าย คลิกที่ **"เติมเครดิต / ชำระเงิน (Top-up)"**
3. ระบบจะแสดงยอดเครดิตคงเหลือปัจจุบันแบบ Real-time และประวัติการทำรายการย้อนหลัง

---

### 2. ช่องทางการเติมเครดิตที่มีให้บริการ
ระบบรองรับ 2 ช่องทางหลัก:

#### ก. ชำระผ่าน Thai QR Payment (PromptPay) - ยอดเข้าทันที 24 ชม.
1. ระบุจำนวนเงินที่ต้องการเติม (เริ่มต้นขั้นต่ำ 50 บาท)
2. เลือกช่องทาง **"PromptPay QR Code"** แล้วกดปุ่ม *ดำเนินการต่อ*
3. ระบบจะสร้าง Dynamic QR Code ที่ระบุยอดเงินตรงตามที่ระบุ
4. เปิดแอปพลิเคชัน Mobile Banking ของทุกธนาคารในไทย (SCB, KBank, KTB, BBL, TTB, GSB ฯลฯ) แล้วสแกน QR Code
5. ตรวจสอบชื่อบัญชีปลายทางและกดยืนยันการโอนเงิน
6. เมื่อทำรายการสำเร็จ ระบบจะตรวจจับยอดเงินและเพิ่มเครดิตเข้าบัญชีของคุณโดยอัตโนมัติภายใน 1-3 วินาที

#### ข. โอนเงินผ่านบัญชีธนาคาร (Bank Transfer & Slip Upload)
1. เลือกช่องทาง **"โอนเงินผ่านธนาคาร"**
2. คัดลอกเลขที่บัญชีธนาคารของบริษัทที่แสดงบนหน้าจอ
3. ทำการโอนเงินผ่าน Mobile Banking หรือตู้ ATM
4. อัปโหลดภาพหลักฐานการโอนเงิน (สลิปการโอนเงิน)
5. ระบุวันและเวลาที่โอนเงินให้ตรงกับสลิป แล้วกดยื่นตรวจสอบ
6. เจ้าหน้าที่ฝ่ายการเงินจะตรวจสอบความถูกต้องและปรับปรุงยอดเครดิตให้ภายใน 5-15 นาที

---

### 3. การนำเครดิตไปใช้งาน
- ชำระค่าแพ็กเกจ Cloud Web Hosting รายเดือน / รายปี
- ชำระค่าจดทะเบียนชื่อโดเมนใหม่ หรือต่ออายุโดเมน
- ชำระบิลค่าใช้จ่ายที่ระบบแจ้งเตือนล่วงหน้า 30 วันก่อนวันครบกำหนดอัตโนมัติ
- สั่งซื้อและต่ออายุ Cloud VPS

## คู่มือการค้นหาและจดทะเบียนชื่อโดเมน (Domain Registration)

MinimalHouse ให้บริการจดทะเบียนชื่อโดเมนสากลระดับโลก (gTLD เช่น .com, .net, .org, .info, .biz ฯลฯ) ผ่าน Registrar Wholesale Gateway คุณภาพสูง พร้อมระบบรักษาความปลอดภัยระดับองค์กร

---

### ขั้นตอนที่ 1: ค้นหาและตรวจสอบสถานะชื่อโดเมน (Domain Search)
1. เข้าสู่ระบบบัญชีผู้ใช้ แล้วไปที่เมนู **"จดทะเบียนโดเมน -> ค้นหา & จดโดเมนใหม่"** (URL: `/client/domain-registry`)
2. พิมพ์ชื่อโดเมนที่ต้องการลงในช่องค้นหา (เช่น `yourbrand.com`) แล้วกดปุ่ม **"ค้นหา"**
3. ระบบจะแสดงสถานะ:
- **พร้อมจดทะเบียน (Available):** แสดงราคาเป็นเงินบาท (THB) พร้อมปุ่มสั่งซื้อ
- **มีผู้จดทะเบียนแล้ว (Taken):** คุณสามารถคลิกดูรายละเอียด **WHOIS Information** เพื่อดูประวัติการจดทะเบียน วันที่เริ่มจด วันหมดอายุ และ Registrar ต้นทางได้

---

### ขั้นตอนที่ 2: ปรับแต่งตัวเลือกการสั่งซื้อ (Order Customization)
1. **เลือกระยะเวลาการจดทะเบียน:** เลือกได้ตั้งแต่ 1 ปี ถึง 10 ปี (ระบบคำนวณราคารวม THB ให้โดยอัตโนมัติ)
2. **บริการพ่วงฟรี (Free Addon):**
- **Cloudflare DNS Management & DDoS Protection (ฟรี ฿0):** ช่วยปกป้องเว็บไซต์จากการโจมตี และกระจายแคชทั่วโลก
3. **บริการพ่วง Cloud Web Hosting (Addon Hosting Package):**
- คุณสามารถเลือกติ๊กถูกสั่งซื้อแพ็กเกจ **Cloud Web Hosting** ควบคู่ไปกับชื่อโดเมนได้ทันทีในขั้นตอนนี้
- เมื่อเลือกสั่งซื้อพ่วง ระบบจะผูกชื่อโดเมนเข้ากับพื้นที่โฮสติ้ง ตั้งค่า vhost และเตรียมฐานข้อมูลให้อัตโนมัติทันทีที่คำสั่งซื้อได้รับการอนุมัติ ไม่ต้องเสียเวลาตั้งค่า DNS เอง
4. **เปิดการต่ออายุอัตโนมัติ (Auto-Renew):**
- หากเปิดใช้งาน ระบบจะสร้างใบแจ้งหนี้ล่วงหน้า 30 วันก่อนครบกำหนด เพื่อให้คุณชำระต่ออายุได้อย่างต่อเนื่อง ป้องกันโดเมนหลุด

---

### ขั้นตอนที่ 3: ยืนยันคำสั่งซื้อและการตรวจสอบของเจ้าหน้าที่ (Staff Verification)
1. ตรวจสอบยอดเงินรวม แล้วกดปุ่ม **"ดำเนินการสั่งซื้อ"**
2. ระบบจะสร้างรายการคำสั่งซื้อและส่งเข้าคิว **รอการตรวจสอบ (Pending Verification)**
3. เจ้าหน้าที่ (Staff) จะทำการตรวจสอบความถูกต้องของข้อมูลผู้ถือครองโดเมน (Registrant Info)
4. เมื่อเจ้าหน้าที่กดยืนยันอนุมัติคำสั่งซื้อ:
- ระบบจะหักเครดิตจาก Wallet ตามจำนวนจริง
- ระบบจะยิงคำสั่งซื้อผ่าน Registrar API ไปยังเครือข่ายสากลทันที
- หากพบปัญหาจาก API ต้นทาง ระบบจะมีกลไก **คืนเครดิตอัตโนมัติ (Auto Refund)** คืนเงินเข้ากระเป๋าของคุณทันที 100%

---

### ขั้นตอนที่ 4: การจัดการโดเมนที่ถือครอง (My Domains Management)
1. ไปที่เมนู **"จดทะเบียนโดเมน -> ทะเบียนโดเมนที่ถือครอง"** (URL: `/client/domain-registry/my-domains`)
2. คุณสามารถ:
- ตรวจสอบวันหมดอายุ และจำนวนวันที่เหลือก่อนครบกำหนด
- เปิดหรือปิด สวิตช์การต่ออายุอัตโนมัติ (Auto-Renew Toggle)
- ดูข้อมูล Nameserver และประวัติบิลค่าใช้จ่ายที่เกี่ยวข้อง
คู่มือใช้งาน Cloud Web Hosting (Cloud Hosting Handbook)

คู่มือการสั่งซื้อแพลน การตั้งค่าเซิร์ฟเวอร์ และการใช้งานเครื่องมือควบคุมโฮสติ้งทุกเมนู

## การสั่งซื้อแพ็กเกจ Cloud Web Hosting และการตั้งค่าเริ่มต้น

MinimalHouse Cloud Web Hosting ทำงานบนสถาปัตยกรรม High-Performance Cloud Node ขับเคลื่อนด้วยระบบแยก Resource อิสระ รองรับทั้งเว็บไซต์ทั่วไปและเว็บแอปพลิเคชันระดับองค์กร

---

### 1. การเลือกแพ็กเกจ Cloud Web Hosting
1. เข้าไปที่เมนู **"บริการของฉัน -> Cloud Web Hosting"** แล้วเลือก **"สั่งซื้อบริการใหม่"**
2. เลือกแพ็กเกจที่ตรงกับความต้องการของเว็บไซต์คุณ:
- **Storage Quota (SSD/NVMe):** พื้นที่เก็บไฟล์เว็บไซต์ รูปภาพ และฐานข้อมูล
- **Bandwidth Limit:** ปริมาณรับ-ส่งข้อมูลต่อเดือน (High-Speed Traffic)
- **MySQL Databases:** จำนวนฐานข้อมูลที่อนุญาตให้สร้างได้
- **Subdomains Limit:** จำนวนโดเมนย่อยที่สามารถเพิ่มได้ เช่น `blog.yourdomain.com`
- **Snapshots Limit:** โควตาการสำรองข้อมูลเว็บไซต์แบบ One-Click Snapshot
3. สำหรับลูกค้าที่ได้รับแพ็กเกจโปรโมชันพิเศษเฉพาะราย (Private/Exclusive Plan) เจ้าหน้าที่จะเปิดสิทธิ์ให้บัญชีของคุณสามารถมองเห็นและสั่งซื้อได้ผ่านหน้าสั่งซื้อเดียวกัน

---

### 2. การผูกชื่อโดเมนเข้ากับโฮสติ้ง
คุณสามารถเลือกใช้งานชื่อโดเมนได้ 2 รูปแบบ:
1. **ใช้ชื่อโดเมนของคุณเอง (Custom Domain):**
- นำชื่อโดเมนของคุณ (เช่น `mybusiness.com`) ไปตั้งค่า DNS โดยชี้ **A Record** ค่า `@` และ `www` มายัง **Proxy IP** ของ MinimalHouse ที่แสดงบนแดชบอร์ด
2. **ใช้งานชื่อโดเมนย่อยฟรี (Free DDNS Subdomain):**
- ระบบแจกโดเมนย่อยฟรี เช่น `myname.minimalcloud.sbs` สามารถใช้งานได้ทันทีโดยไม่ต้องจดโดเมนใหม่ เหมาะสำหรับเว็บไซต์ทดสอบหรือโปรเจกต์ส่วนตัว

---

### 3. การเปิดใช้งาน SSL Certificate ฟรี (HTTPS)
1. หลังจากผูกชื่อโดเมนและชี้ DNS เรียบร้อยแล้ว ให้เข้าไปที่หน้าจัดการโฮสติ้ง
2. ไปที่แท็บ **"SSL / TLS Certificate"**
3. กดปุ่ม **"ขอรับใบรับรอง SSL อัตโนมัติ (Issue Let's Encrypt SSL)"**
4. ระบบจะทำการตรวจสอบความเป็นเจ้าของโดเมนและออกใบรับรองแบบ 256-bit Encryption ให้ทันที ทำให้เว็บไซต์ของคุณปลอดภัยและแสดงเครื่องหมายกุญแจเขียว (HTTPS)

## คู่มือการใช้งานเครื่องมือควบคุม Cloud Web Hosting ครบทุกฟังก์ชัน

เมื่อเข้าสู่หน้าจัดการโฮสติ้ง (URL: `/client/cloud-hosting/{id}`) คุณจะพบแถบเครื่องมือควบคุมระดับมืออาชีพ ดังนี้:

---

### 1. Web File Manager (ตัวจัดการไฟล์ออนไลน์)
- **ตำแหน่งโฟลเดอร์หลัก:** โฟลเดอร์สำหรับอัปโหลดไฟล์เว็บไซต์สู่สาธารณะคือ `/public_html`
- **โปรแกรมแก้ไขโค้ดในตัว (Code Editor):** รองรับ Syntax Highlighting เสมือนใช้งาน VS Code บนบราวเซอร์ สามารถแก้ไขไฟล์ HTML, PHP, CSS, JS ได้ทันที
- **เครื่องมือบีบอัดไฟล์:** รองรับการอัปโหลดไฟล์ `.zip` และแตกไฟล์ (Extract) บนเซิร์ฟเวอร์โดยตรง

---

### 2. การเชื่อมต่อ SFTP / SSH (Secure File Transfer)
- หากต้องการอัปโหลดโปรเจกต์ขนาดใหญ่ แนะนำให้ใช้โปรแกรม **FileZilla**, **Cyberduck** หรือ **WinSCP**
- **พอร์ตการเชื่อมต่อ:** พอร์ตมาตรฐาน `22`
- **Host / Server:** ระบุ IP หรือ Hostname ที่ระบุในหน้าแดชบอร์ด
- **Username & Password:** ใช้ข้อมูลบัญชีผู้ใช้ระบบโฮสติ้งที่ระบบออกให้

---

### 3. ระบบจัดการฐานข้อมูล (MySQL Databases & phpMyAdmin)
- **สร้างฐานข้อมูลใหม่:** กดสร้างฐานข้อมูล กำหนดชื่อ Database และรหัสผ่าน
- **phpMyAdmin:** มีปุ่มคลิกเดียวเข้าสู่หน้าต่าง phpMyAdmin อัตโนมัติ (Single Sign-On) สำหรับ Import/Export ไฟล์ `.sql` และจัดการตารางข้อมูล

---

### 4. ปรับเปลี่ยนเวอร์ชัน PHP และ Directives Config (PHP Selector)
- **เลือกเวอร์ชัน PHP:** สลับเปลี่ยนเวอร์ชันระหว่าง PHP 8.0, PHP 8.1, PHP 8.2, PHP 8.3 และ **PHP 8.4** ได้ทันทีตามที่สคริปต์ของคุณต้องการ
- **ปรับแต่งค่า PHP Config:**
- `upload_max_filesize`: เพิ่มขนาดรองรับการอัปโหลดไฟล์ได้สูงสุด 1,024 MB
- `post_max_size`: เพิ่มขนาดรับส่งข้อมูล POST
- `memory_limit`: จัดสรรหน่วยความจำ RAM สำหรับประมวลผลสคริปต์
- **ปุ่มรีสตาร์ท PHP-FPM:** สามารถกดคำสั่งรีสตาร์ท Process ของ PHP ได้ทันทีเมื่อต้องการเคลียร์ OpCache หรือโหลดค่า config ใหม่

---

### 5. การจัดการอีเมลองค์กร (Corporate Email & Webmail)
- **สร้างกล่องจดหมาย:** สร้างอีเมลตามชื่อโดเมนของคุณ เช่น `support@yourdomain.com`
- **กำหนดโควตา:** จัดสรรขนาดพื้นที่จัดเก็บสำหรับแต่ละกล่องจดหมาย
- **เข้าใช้งาน Webmail:** รองรับเว็บเมลมาตรฐาน Roundcube เข้าใช้งานได้ทุกที่ทั้งบนคอมพิวเตอร์และมือถือ

---

### 6. การติดตั้งแอปพลิเคชันใน 1 คลิก (1-Click App Installer)
- **WordPress:** กดปุ่มเดียว ระบบจะดาวน์โหลด Core ล่าสุด สร้างฐานข้อมูล MySQL และติดตั้ง vhost พร้อมใช้งานใน 5 วินาที
- **Laravel Framework:** รองรับโครงสร้าง Laravel โฟลเดอร์ `public` พร้อมรัน Composer และตั้งค่า Permissions ให้อัตโนมัติ

---

### 7. การเชื่อมต่อ Git Auto Deploy (Plesk/cPanel Git Flow)
- รองรับการดึงโค้ดอัตโนมัติจาก **GitHub**, **GitLab** หรือ **Bitbucket**
- ระบุ Repository URL และ Branch (เช่น `main` หรือ `production`)
- นำ **Webhook URL** ไปผูกที่ GitHub เมื่อคุณสั่ง `git push` เซิร์ฟเวอร์จะทำการ Pull โค้ดล่าสุดมาอัปเดตเว็บให้อัตโนมัติทันที

---

### 8. การสำรองข้อมูล (Snapshots) และ Cron Jobs
- **Snapshots:** สร้างจุดบันทึกสำรองข้อมูลไฟล์และฐานข้อมูลทั้งระบบ สามารถกดย้อนเวลากลับมา (Restore) ได้ตลอดเวลาเมื่อเกิดข้อผิดพลาด
- **Cron Jobs:** กำหนดเวลาสั่งรันคำสั่ง PHP หรือสคริปต์เบื้องหลังอัตโนมัติ มีพรีเซ็ตสำเร็จรูปให้เลือกใช้งาน

### ⚠️ ข้อควรระวังและแนวทางปฏิบัติที่ปลอดภัย (Best Practices)
1. **ความปลอดภัยของรหัสผ่าน:** ห้ามใช้รหัสผ่านเดียวกับอีเมลส่วนตัว และควรมีความยาวไม่ต่ำกว่า 10 ตัวอักษร
2. **การอัปโหลดไฟล์:** ตรวจสอบสิทธิ์ Folder Permissions ไม่ควรตั้งค่าเป็น `777` ให้ใช้ `755` สำหรับโฟลเดอร์ และ `644` สำหรับไฟล์
3. **การสำรองข้อมูล:** ควรสร้าง Snapshot อย่างน้อยสัปดาห์ละ 1 ครั้ง หรือก่อนการอัปเกรดปลั๊กอิน/ธีมเว็บไซต์ใหญ่ทุกครั้ง

## ประกาศการเปิดตัวระบบ Wholesale Domain Gateway และ Cloudflare DNS

MinimalHouse ได้เปิดตัวบริการจดทะเบียนชื่อโดเมนผ่าน Registrar Wholesale Gateway มาตรฐานระดับโลก พร้อมฟังก์ชันระดับ Enterprise:

### ไฮไลท์การพัฒนาและฟังก์ชันใหม่
1. **Wholesale Domain Registry:** ค้นหาและจดทะเบียนชื่อโดเมนสากล (.com, .net, .org ฯลฯ) ในราคาต้นทุนขายส่ง คำนวณเป็นเงินบาท (THB) เที่ยงตรงตามอัตราแลกเปลี่ยนจริง
2. **Domain Order Verification Queue:** เจ้าหน้าที่ตรวจสอบคำสั่งซื้อก่อนตัดเครดิตและยิงคำสั่งจดทะเบียน พร้อมระบบคืนเงินอัตโนมัติ (Auto-Refund) ปลอดภัย 100%
3. **Auto Cloudflare DNS Integration:** ระบบเชื่อมต่อ DNS เข้ากับ Cloudflare DNS อัตโนมัติ ป้องกันการโจมตีทางไซเบอร์และซ่อน IP แท้จริงของเครื่องเซิร์ฟเวอร์
4. **Cloud Web Hosting Addon:** ลูกค้าสามารถสั่งซื้อโดเมนพ่วงแพ็กเกจโฮสติ้งได้ในขั้นตอนเดียว ระบบผูกข้อมูลและพร้อมใช้งานทันที
